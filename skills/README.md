# Skill library

From the new repo's root, install a skill by name:

```bash
bash /Users/sameer.ahmad/Desktop/CODE/skills/skills/setup.sh general
```

Pass several names to install more than one (`... setup.sh general ui`). Reload the Cursor window afterward.

| Skill | What it adds |
|-------|--------------|
| `general` | Senior-engineer defaults: principles, output style, code and README conventions, mermaid diagrams for agent flows. |
| `ui` | Next.js / HC2-UI instructions: execution and communication rules, site header links, Reports proxy, downloads, and AG Grid conventions. |
